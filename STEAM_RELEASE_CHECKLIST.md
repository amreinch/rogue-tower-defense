# Steam Release Checklist

## Pre-Release Development

### Content (Estimated: 1-3 months)
- [ ] 8-10 tower types minimum
- [ ] 10-15 enemy types
- [ ] 3-5 map themes (visual variety)
- [ ] 20+ waves of content
- [ ] Tutorial/help screen
- [ ] Achievements (10-20)
- [ ] Sound effects for all actions
- [ ] Background music (3-5 tracks)
- [ ] Particle effects (explosions, hits)
- [ ] Screen shake/juice

### Polish
- [ ] Replace placeholder graphics with professional sprites
- [ ] UI polish (buttons, tooltips, transitions)
- [ ] Balance testing (can reach wave 20+)
- [ ] Bug fixing (no crashes, no exploits)
- [ ] Performance optimization (60 FPS on low-end PCs)
- [ ] Accessibility (colorblind mode, key remapping)

### Build
- [ ] Build for Windows (64-bit minimum)
- [ ] Build for Mac (Intel + Apple Silicon if possible)
- [ ] Build for Linux (optional but recommended)
- [ ] Test builds on each platform
- [ ] Installer/package for each platform

## Pricing Strategy

### Launch Pricing
**Recommended:** $7.99 - $9.99
- Sweet spot for indie tower defense
- Impulse-buy price point
- Room for sales discounts

**Alternative:** $4.99 - $6.99
- Lower barrier to entry
- More unit sales
- Budget-friendly

### Regional Pricing
- [ ] Enable Steam's auto-regional pricing
- [ ] Or manually set prices for key regions:
  - USD: $7.99
  - EUR: €7.99
  - GBP: £6.99
  - etc.

### Discount Strategy
- Launch: Full price
- Week 1 sale: -10% (build momentum)
- Steam seasonal sales: -25% to -50%
- Never go below 50% off in first year

## Revenue Expectations

### Conservative Estimates
- 100 copies @ $7.99 = $799 gross
- After Steam cut (30%): **$559 net**
- After fee refund: **$659 net**

### Moderate Estimates
- 500 copies @ $7.99 = $3,995 gross
- After Steam cut: **$2,797 net**

### Success Scenario
- 1,000+ copies = **$5,593+ net**
- 5,000+ copies = **$27,965+ net**
- 10,000+ copies = **$55,930+ net**

### Factors for Success
- Quality (gameplay, graphics, polish)
- Marketing (pre-launch wishlist, streamers)
- Reviews (positive Steam reviews crucial)
- Timing (avoid major releases)
- Updates (post-launch content)
- Sales (discount during Steam events)
